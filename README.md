# PC Performance Lab

Aplicativo para diagnóstico, monitoramento e otimização de computadores Windows.

## Download

[Baixar a versão mais recente](https://github.com/jcfms/performance-lab-releases/releases/latest)

Abra a versão disponível e, em **Assets**, baixe o instalador.

## Requisitos

- Windows 64 bits
- Permissão de administrador para instalar e executar

O Windows pode exibir um aviso porque o instalador usa um certificado autoassinado.
